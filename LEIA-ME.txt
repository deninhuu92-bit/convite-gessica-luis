COMO PUBLICAR PELO GITHUB + VERCEL

1. Extraia o ZIP.
2. Crie um repositório no GitHub e envie o CONTEÚDO da pasta
   Gessica_Luis_Vercel. O arquivo vercel.json e a pasta public devem
   aparecer diretamente na raiz do repositório.
   Preserve a pasta public/assets ao enviar os arquivos.
3. Na Vercel, escolha Add New > Project e importe o repositório.
4. Confira as opções:
   Framework Preset: Other
   Root Directory: raiz do repositório (não escolha public)
   Build Command: vazio
   Output Directory: public
   Install Command: vazio
   Environment Variables: nenhuma
   O vercel.json já declara essas configurações.
5. Clique em Deploy. Use o endereço de produção fornecido pela Vercel.
6. Abra o endereço em uma janela anônima e no celular para verificar
   o acesso dos convidados e as animações.
   Se aparecer uma exigência de login da Vercel, confira Deployment
   Protection nas configurações do projeto para permitir os convidados.

OPÇÃO PELO TERMINAL

Com Node.js disponível, abra o terminal dentro da pasta que contém
vercel.json e execute:

  npx vercel --prod

Entre na sua conta e siga as perguntas para criar o projeto.

PARA CONFERIR NO COMPUTADOR ANTES DE PUBLICAR

Abra public/index.html no navegador. Não há dependências para instalar.
A confirmação abre o WhatsApp e só é concluída quando o convidado
ENVIA a mensagem. Não basta clicar no botão.

CONTAGEM DE VOTOS

Esta entrega não contém contagem compartilhada nem banco de dados.
Os nomes e respostas não são armazenados por um servidor do convite.

para Gessica. O palpite local serve apenas para lembrar a escolha
naquele navegador.
