COMO PUBLICAR PELO GITHUB + VERCEL

1. Extraia o ZIP.
2. Crie um repositório no GitHub e envie o CONTEÚDO da pasta
   Gessica_Luis_Vercel. O arquivo vercel.json e a pasta public devem
   aparecer diretamente na raiz do repositório.
   Preserve a pasta public/assets ao enviar os arquivos.
3. Na Vercel, escolha Add New > Project e importe o repositório.
4. Confira as opções:
   Framework Preset: Other
   Root Directory: raiz do repositório (não escolha public)
   Build Command: vazio
   Output Directory: public
   Install Command: vazio
   Environment Variables: nenhuma
   O vercel.json já declara essas configurações.
5. Clique em Deploy. Use o endereço de produção fornecido pela Vercel.
6. Abra o endereço em uma janela anônima e no celular para verificar
   o acesso dos convidados e as animações.
   Se aparecer uma exigência de login da Vercel, confira Deployment
   Protection nas configurações do projeto para permitir os convidados.

OPÇÃO PELO TERMINAL

Com Node.js disponível, abra o terminal dentro da pasta que contém
vercel.json e execute:

  npx vercel --prod

Entre na sua conta e siga as perguntas para criar o projeto.

CONTAGEM DE VOTOS

Esta versão conecta a parcial ao projeto Supabase já configurado.
Tabela: public.convite_gl_palpites
Funções: convite_gl_votar e convite_gl_parcial

A chave incluída em public/assets/votos.js é a chave PUBLICÁVEL,
adequada ao navegador. Não há senha, service_role ou chave secreta.

A parcial aparece abaixo do palpite com totais e porcentagens,
consultando novos resultados a cada 30 segundos enquanto a etapa
estiver visível. O botão de tentar novamente aparece se houver erro.

O navegador guarda um identificador aleatório. Trocar o palpite
atualiza o mesmo registro, sem acrescentar outro voto nesse navegador.
Limpar os dados ou usar outro navegador pode permitir outro voto;
não é uma verificação da identidade da pessoa.

O nome e a presença continuam somente na mensagem do WhatsApp.
A contagem registra a escolha no site, mesmo se a mensagem não for enviada.
Palpites antigos feitos antes desta atualização precisam ser tocados
novamente para entrar na parcial.
